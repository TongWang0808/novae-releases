安装与升级

下载 novae.exe，建议放在一个固定目录，例如 D:\Apps\Novae。
直接替换旧版 Novae.exe。账号、登录态、歌单、最近播放与下载记录保存在 WebView2 用户目录，不会被覆盖。
首次启动如遇 Windows SmartScreen，点击“更多信息 → 仍要运行”。这是未购买代码签名证书时的正常提示。
启动后可在“设置 → 关于”查看版本；1.4.0 的文件版本与产品版本均为 1.4.0.0。
升级不需要卸载旧版，也不建议删除用户数据目录；直接替换 exe 是保留登录态与历史记录最稳妥的方式。

七个平台登录

打开“账号中心 → 添加账号”，选择平台后会显示该平台实际的“登录入口”。不同平台不能共用一套假登录，必须走各自官方入口。

平台登录入口说明
QQ 音乐网页登录 / QQ / 微信扫码或账号授权后回读昵称、歌单、喜欢与最近播放。
酷狗音乐扫码网页 token 与 API 端不通用，扫码后由内置 KuGouMusicApi 同步。
酷我音乐网页登录内置接口直连，支持账号资料、喜欢与歌单。
网易云音乐扫码 / 手机号可只登录平台，也可额外配置云端 API。
华为音乐网页登录华为账号授权后同步歌单、喜欢与会员信息。
汽水音乐扫码（主）/ 手机号验证码（备用）遇到 2046 二次验证时，优先在官方验证宿主完成短信 / 滑块。
波点音乐扫码用波点 App 扫码；微信 / QQ / 手机号先在波点 App 内完成。
汽水、波点不依赖外部音乐 API。登录会话只保存在本机；如果平台要求图形验证或风控校验，请改在官方 App 内完成。

汽水会员整曲

汽水 Web 接口对会员曲目只下发 30 秒试听。要播放完整整曲，Novae 需要 PC 端签名器，并对返回的 CENC MP4 做本地解密。

方式一：本机 SodaM signer

安装并运行 SodaM 后，Novae 会读取 %APPDATA%\sodam\config.json 中的 signer_url 与 signer_token。不需要在 Novae 里重复填写。

方式二：环境变量

在启动 Novae 前设置：

QISHUI_SIGNER_URL 与 QISHUI_SIGNER_TOKEN。适合把签名服务部署在另一台机器或容器里。

没有签名器时，Novae 会自动回退到公开流或 30 秒试听，不会把加密容器直接交给播放器。签名 token 只在内存中使用，不写入日志。

最近播放与播放队列

最近播放按“实际开播源”归属

播放会话创建时记录默认音源，实际开播只写一次。预加载、自动续播、切音质都不会重复插入；手动切到 API 源时归属切换。QQ、酷狗、网易云在开播后异步回写官方最近播放。

播放队列固定 5 行

队列不再分页，也没有页码下拉框。完整列表一次展开，当前视口固定 5 行；第 6 首起由右侧滚动条承载。5 行高度按实际行高测量，兼容 90% / 100% / 110% / 125% / 150%。

沉浸模式下队列卡使用 90% --bg-elevated 实底，不再出现 64% 透明浮层透出背景的问题。

缩放与接口地址

界面缩放

在“设置 → 外观 → 界面缩放”选择 90% / 100% / 110% / 125% / 150%。切换后当前页面立即按新档重排；低分辨率设备建议优先使用 90% / 100% / 110%。

接口地址脱敏

设置页不会再明文显示真实地址。占位示例为 xxx.xxx.xxx.xxx:xxx 或 http://xxx.xxx.xxx.xxx:xxx；已配置地址默认完整脱敏并只读，点击右侧眼睛按钮才显示真实地址并允许编辑。账号卡里的“接口地址”使用同一套脱敏规则。

这是为了避免录屏、截图或远程协助时把内网 IP、端口和 API 地址直接暴露出去；需要修改时再点眼睛。

更新与校验

常见问题

启动后白屏 / 页面空白

确认系统已安装 WebView2 Runtime；如仍空白，删除缓存目录后重启。不要删除整个用户数据目录，否则登录态会丢失。

汽水扫码后要求二次验证

这是汽水 2046 风控。优先使用官方验证宿主完成短信 / 滑块；如果官方窗口已完成但汽水仍未确认，请在汽水 App 内重新登录后再扫码。

汽水会员歌只能听 30 秒

说明没有检测到签名器。检查 %APPDATA%\sodam\config.json 是否存在，或设置 QISHUI_SIGNER_URL / QISHUI_SIGNER_TOKEN；签名器不可用时 Novae 会回退试听。

波点为什么不能新建歌单

波点暂不支持在 Novae 内新建歌单；请在波点 App 创建后同步，Novae 内可加入 / 移出已有歌单。

接口地址为什么显示成 xxx

这是默认脱敏。点击输入框右侧的眼睛按钮即可显示真实地址并编辑；再次隐藏后恢复脱敏。

更新后账号需要重新登录吗

正常覆盖 exe 不需要。只有删除 WebView2 用户目录、手动清空登录态，或平台侧 token 过期时才需要重新登录。

播放失败但平台网页能播

可能是会员、地区、版权或平台风控限制。可尝试切换音质、切换云端 API，或在账号页重新登录；Novae 不绕过平台鉴权。

Novae 为独立实现，与各音乐平台及其关联公司没有隶属、合作或代理关系。各平台名称、会员名称与相关权利归对应公司所有。Novae 不内置音源、账号或会员凭据，不破解 DRM。本指南随 1.4.0 更新。
