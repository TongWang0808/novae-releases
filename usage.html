FEATURES

不是换皮网页，
是一台真正能用的播放器。

多平台账号、跨平台最近播放、逐行歌词、玻璃主题与按压反馈，都在同一个原生桌面窗口里完成。

五个平台，一个窗口

华为音乐、QQ 音乐、网易云音乐、酷狗音乐、酷我音乐可以同时登录、随时切换。平台账号与自建 API 都能设为默认音源，平台只给试听片段时还能用辅助音源补全。

多账号并存 · 平台 / API 混合音源

最近播放，跟着账号走

从各平台官方客户端同步最近播放，切换账号后自动拉取；我喜欢的音乐、平台歌单、下载与本地音乐都在同一层页面里。

跨平台历史 · 实时刷新

沉浸歌词与玻璃光感

全屏沉浸歌词逐行高亮，封面模糊背景、翻译歌词、字号行距都可调。玻璃表面、鼠标扫光与统一按压形变贯穿全应用。

逐行歌词 · 12 套主题

下载、队列与音质都认真做

批量筛选下载、音质档位实测、播放失败自动降档、倍速与定时关闭、队列拖动排序；试听片段不会被当成完整歌曲保存。

批量下载 · 实测码率

歌手、专辑与联想搜索

搜索页分歌手、专辑、歌曲三级结果，歌手页有大卡片、简介展开与歌曲排序；搜索联想和最近搜索都在输入框下方自然接住。

三级结果 · 卡片光效

双源更新，不强制、不自动下载

GitHub 不稳定时可以切到 Gitee 检查更新。发现新版本只亮红点和更新说明，下不下载由你决定；设置页「关于」还能直接看到版本、校验值与使用人数。
