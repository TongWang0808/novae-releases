One Window

不用在七个网页之间，
来回寻找同一首歌。

登录、歌单、最近播放、歌词与音质，被收进同一扇窗。平台还是原来的平台，操作却只需要一次。

为 Windows 桌面设计 · 不内置音源与会员凭据

Features

复杂留在后台，
桌面只留下音乐。

把平台差异、登录态与取流策略挡在界面之外，剩下的是一台可以长时间使用的播放器。

Accounts

一个账号中心。

七个平台同时登录、随时切换。每个平台都保留自己的官方登录入口，不做统一假登录，也不绕开平台鉴权。

扫码、QQ / 微信、手机号与网页授权 会员状态、到期时间与账号资料一屏看清 登录完成后自动关窗，不留下后台进程

Listen

退到只剩音乐。

大屏沉浸播放把封面、歌词与播放控制重新排布。界面不会抢走注意力，切歌、调音质、看歌词都仍在手边。

逐行歌词与翻译开关，缺失时自动走备用链路 平台取流失败时切换云端音源，不中断当前播放 播放队列完整展开，当前视口固定五行

Craft

手感，也是设计。

从玻璃表面的厚度，到按钮按下时的形变，再到指针划过界面的光斑。细节不喧哗，但每一次操作都有一致回应。

01 / LAYOUT

真实逻辑宽度

推荐页、账号页、设置页、队列与搜索页按逻辑宽度重排，窄档不出现被裁掉的按钮。

02 / QUEUE

五行可视区

队列不分页，完整列表一次展开；第六首起交给右侧滚动条，位置始终稳定。

03 / FALLBACK

平台与云端兜底

平台接口不可用时切到云端 API，API 失败再回平台，不因一个请求结束整段播放。
